# Whisk & Wonder

A baking club website for 8 to 12 year olds. It has European recipes, a planner for three family bakes a week, tickable shopping lists for Tesco, Co-op or Lidl, Baking School lessons with quizzes, a Baking Passport, badges and a baking journal.

## What's in this folder

- `index.html` is the whole website (styles, pictures and code are all inside).
- `fonts/` holds the two typefaces (Bagel Fat One and Nunito), hosted with the site so no outside font service is used. Both are free under the SIL Open Font License; the licence files are included.

## Put it on GitHub Pages

1. Create a new public repository on GitHub, for example `whisk-and-wonder`.
2. Upload `index.html` and the `fonts` folder to the top level of the repository.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
5. After a minute or two the site is live at `https://<your-username>.github.io/whisk-and-wonder/`.

## Privacy

- No accounts, no logins, no forms that send anything, no analytics, no cookies, no third-party scripts and no outside font or image requests.
- The child's name, plans, ticks and journal are saved only in the browser on that device (`localStorage`). They are never sent to any server.
- Clearing the browser's site data, or using a private window, wipes them. A different device or browser starts fresh.
- GitHub, as the host, keeps standard server logs (such as IP addresses) for security. The site owner cannot see these. See GitHub's privacy statement for details.
